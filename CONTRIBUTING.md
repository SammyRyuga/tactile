# Contributing to Tactile

1. Fork or branch from the latest `main`. Use a descriptive branch name such as `fix/demo-export`.
2. Run `npm ci` and `npm run dev`. Start with the bundled demo to understand the flow.
3. Make a focused change. Run `npm run format` followed by `npm run check`.
4. Walk through the affected flow in the browser. Include your verification in the pull request and update `progress.md` for a user-visible milestone.
5. Open a pull request describing the change, how to try it, and any parts a reviewer should inspect.

Use [GitHub Issues](https://github.com/SammyRyuga/tactile/issues) for bugs and feature requests. Include the Node.js version, the steps you followed, and what you expected. Share sanitized examples and keep credentials and private proposals out of issues and pull requests.
