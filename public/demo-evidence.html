Bundled demo evidence

A minimal example of how a changed-package-only rule can miss a test failure in a dependent package.

Dependency replay

Package checkout depends on the schema package. A change renames total to amount. Run this replay with Node to reproduce the difference. 

import assert from "node:assert/strict";
const schema = () => ({ amount: 12 });
assert.equal(schema().amount, 12); // Changed package passes.
assert.equal(schema().total, 12);  // Existing checkout contract fails.

Replica timeline

Illustrative ordering for an asynchronous replica. The elapsed times are fixture inputs.

42 ms  replica replays the commit
50 ms  repeated lookup returns order 42

Feature flag timeline

In this example, the flag is evaluated on each new request and the update persists in storage. 

Flag ON   request A uses the new writer, updating record 7
Flag OFF  request B uses the old writer
Read 7    the update from request A is still present
