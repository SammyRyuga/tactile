Bundled demo evidence

A minimal example of how a changed-package-only rule can miss a test failure in a dependent package.

Dependency replay

Package checkout depends on the schema package. A change renames total to amount. Run this replay with Node to reproduce the difference. 

import assert from "node:assert/strict";
const schema = () => ({ amount: 12 });
assert.equal(schema().amount, 12); // Changed package passes.
assert.equal(schema().total, 12);  // Existing checkout contract fails.

Rollout configuration

The example CI policy chooses the test command by event. A full run on main catches the failure after merge. No timing measurements are bundled. 

pull_request → changed packages
push to main → full suite
